# अनुवाद संबंधी सूचनाएँ {#translation-notices}

अनुवादित documentation site के हर page के ऊपर इनमें से एक सूचना दिखती है।

## मशीनी अनुवाद {#translated}

यह page अंग्रेज़ी documentation से अपने-आप अनुवादित किया गया है, और [अंग्रेज़ी page](ENGLISH_PAGE) ही प्रामाणिक version है। अगर कुछ गलत लगे, तो [अनुवाद](TRANSLATIONS_PAGE) page बताता है कि इसकी सूचना कैसे दें।

## अंग्रेज़ी page से पीछे रह गया अनुवाद {#outdated}

यह अनुवाद बनने के बाद अंग्रेज़ी page बदल गया है, इसलिए इसके कुछ हिस्से पुराने हो सकते हैं। शक हो तो [अंग्रेज़ी page](ENGLISH_PAGE) पढ़ें; [अनुवाद](TRANSLATIONS_PAGE) page बताता है कि अनुवादित documentation कैसे काम करती है।

## अंग्रेज़ी में दिखाया गया {#english}

इस page का कोई मौजूदा अनुवाद नहीं है, इसलिए आप इसे अंग्रेज़ी में पढ़ रहे हैं। [अनुवाद](TRANSLATIONS_PAGE) page बताता है कि अनुवादित documentation कैसे काम करती है।
